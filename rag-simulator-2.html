How RAG Works

Follow the 6 key steps from your data to a grounded answer.

▤
1. Ingest & Process

Load data, extract content, chunk and create embeddings.

▤
2. Store

Save vectors and metadata in a searchable index.

⌕
3. Retrieve

Search with vector, keyword or hybrid search.

☷
4. Rerank

Reorder and select the most relevant chunks.

▤
5. Augment

Combine system prompt, user query and context.

✧
6. Generate

LLM produces a grounded answer with evidence.
